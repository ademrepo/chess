# Knight's Tour

Problème du cavalier résolu par un algorithme génétique (Python + pygame, projet de Problem Solving).
Installation : `pip install pygame`
Lancement : `python main.py` (le calcul se fait d'abord, puis le chat parcourt le meilleur chemin).
Touches : espace = lecture / pause, R = relancer un nouveau run.
Boutons : lecture, relancer, vitesse d'animation (engrenage).
