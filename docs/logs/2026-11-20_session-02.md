## Decisions taken and why
- Pieces: chess.com's images are proprietary, so we use the open cburnett set. The chess.com look is
  imitated only with colours and shapes drawn by the code (listed in `specs/ASSETS.md`).
- Manual play reuses `Knight.move_forward / move_backward`: same rules for the human and the algorithm.
- The algorithm runs in a thread (`gui/ga_job.py`) so the window stays responsive; the interface adds a
  10 000 generations safety limit and a Cancel button. The console mode has no limit (as the statement).
- The algorithm always starts at (0, 0) and starts a new game when the button is pressed.
- Rendering of SVG: `pygame.image.load_sized_svg` (pygame-ce), no extra library.
